# MERE — 3D visualisation

Interactive 3D presentation of a planned single-family house in Tammneeme (Viimsi, Estonia).

- Built with three.js, static files only (GitHub Pages).
- House geometry, facades and materials are generated from the building design drawings (AB Standup OÜ, job 25121201); placement uses L-EST97 corner coordinates from the site plan.
- Ground: orthophoto © Maa- ja Ruumiamet (Estonian Land and Spatial Development Board).
- Interior furnishing is illustrative.

Languages: ET / EN / RU (`?lang=et|en|ru`).
